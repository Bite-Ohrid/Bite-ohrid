# Bite Ohrid Website

This is a responsive, single-page website for **Bite Ohrid**, a modern café and hookah lounge in Ohrid, North Macedonia.

## Features
- Mobile-first, responsive design
- Warm, earthy color palette tailored for a cozy café vibe
- Tabbed menu for Coffee, Food, and Hookah
- Smooth scrolling and scroll-triggered animations
- Embedded Google Maps
- Pure HTML, CSS, and vanilla JavaScript (no frameworks)

## File Structure
- `index.html` - The main HTML document containing all sections.
- `css/style.css` - All styling, CSS variables, and responsive queries.
- `js/script.js` - Tab switching logic, mobile menu toggle, and Intersection Observer for animations.

## How to Run
Simply open `index.html` in any modern web browser. No local server is required.

## Customization
- **Logo:** Replace the empty `src` attribute in the `img#logo` tag in `index.html` with your actual logo URL and set `style="display:block;"`. Hide the `span.logo-text`.
- **Contact Info:** Update the phone number and exact address in the Contact section of `index.html`.
- **Social Links:** Replace the `#` hrefs with the actual URLs for Instagram, Facebook, and TikTok.
